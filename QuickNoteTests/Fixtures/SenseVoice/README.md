# Public integration test audio

`zh.wav` is the unmodified Chinese example from the official sherpa-onnx
SenseVoiceSmall int8 2024-07-17 model release (FunAudioLLM / Alibaba Group).
Source: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models
The model's notices are retained in QuickNote/Resources/Speech/MODEL_LICENSE.

This short public sample validates native decoding and number rendering, not
a representative accuracy benchmark. It contains no user recording.
