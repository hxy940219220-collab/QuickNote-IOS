# 编辑器撤回功能设计

## 目标

为便签编辑器提供与 `Command + Z` 一致的逐步撤回能力。一次撤回恢复最近一次文字编辑或格式操作，包括富文本属性和光标选区。

## 交互

- 在顶部格式工具栏的“格式”按钮左侧增加 `arrow.uturn.backward` 撤回按钮。
- 按钮和 `Command + Z` 共用 macOS 原生撤销历史。
- 没有可撤回操作时按钮置灰。
- 普通连续输入沿用 AppKit 的系统合并规则；一次工具栏格式命令作为一步撤回。
- 本次不增加跨重启版本历史；重做继续使用系统 `Command + Shift + Z`。

## 实现

- 复用 `NSTextView` 已启用的 `NSUndoManager`，不维护第二套快照栈。
- `RichTextEditorController` 暴露撤回动作和可撤回状态，工具栏只负责展示与触发。
- 自定义格式命令通过 AppKit 文本编辑事务注册撤销，使文字和属性变化进入同一条原生历史。
- 切换便签时使用新编辑器内容，旧便签的撤销记录不得改写当前便签。

## 验证

- 输入文字后可由按钮撤回。
- 应用粗体等格式后，一次撤回同时恢复原格式与选区。
- 无历史时按钮不可用。
- 切换便签后撤回不会恢复另一条便签的内容。
