# QuickNote 帮助栏精简与文件夹设计

## 目标

- 将帮助栏压缩为用户能快速扫完的快捷键与授权入口。
- 在便签抽屉中加入可创建、展开和管理的单层文件夹。
- 文件夹可以为空；一条便签最多属于一个文件夹。

## 非目标

- 不支持多级文件夹、拖放归档、智能文件夹或云同步。
- 不改变现有标签、置顶和搜索语义。

## 数据设计

新增 SwiftData 模型 `NoteFolder`：

- `id: UUID`，唯一标识。
- `name: String`，展示名称；保存前去除首尾空白，同名文件夹不区分大小写。
- `createdAt: Date`，用于稳定排序。

在 `NoteRecord` 增加可选的 `folderID: UUID?`。`nil` 表示“未分类”。使用标识关联而不是 SwiftData relationship，避免为单层归档引入双向关系和级联删除行为。

仓储层提供最小操作：查询、创建、重命名和删除文件夹，以及将便签移动到指定文件夹。删除文件夹时先把其中便签的 `folderID` 清空，再删除文件夹，绝不连带删除便签。

## 抽屉交互

- 标题栏保留“新建便签”，并新增 SF Symbol `folder.badge.plus` 按钮。
- 点击新建文件夹后显示原生输入框；确认后创建空文件夹。
- 非搜索状态下，文件夹位于顶层，使用原生 disclosure 交互展开其中便签；展开状态仅属于当前界面会话。
- 未归档便签显示在“未分类”分组。
- 便签的 `···` 菜单新增“移动到文件夹”子菜单；已归档便签可选择“移至未分类”。
- 文件夹的 `···` 菜单支持重命名与删除。删除确认文案明确说明便签会移到“未分类”。
- 搜索状态下平铺展示匹配便签，避免用户需要逐个展开文件夹。
- 置顶只影响同一分组内的便签顺序，不把便签移出所属文件夹。

任何持久化错误使用系统错误提示反馈，不静默吞掉；创建名称为空或重复时保持输入框并显示简短错误。

## 帮助栏

移除编号、长段解释和滚动内容，改成两个紧凑快捷键区块：

1. `双击 Command`：快速打开或收起 QuickNote；保留“隐私与安全性 → 输入监控”和打开设置按钮。
2. `Option + 空格`：分析当前选中的文字；保留“隐私与安全性 → 辅助功能”和打开设置按钮。

API Key 仅保留一句：`API Key 仅保存在这台 Mac 的系统钥匙串中；AI 内容只发送给当前服务商。`

## 验证

- 仓储测试：可以创建空文件夹。
- 仓储测试：便签可以移入文件夹和移回未分类。
- 仓储测试：删除文件夹后文件夹消失，原便签仍存在且变为未分类。
- 运行现有 QuickNote 测试和 Release 构建，确认旧数据、便签编辑、删除与搜索流程继续编译通过。
- 安装后手动检查帮助栏高度、文件夹展开、移动菜单和删除确认文案。
